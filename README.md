# Nilo landing page

Landing page for [Nilo](https://github.com/Nearx-Labs/nilo), an investment bot on Stellar. A static Next.js
page with an interactive walkthrough of how an investment flows.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- The page is in Brazilian Portuguese for now; an English version comes later.
- It presents Nilo as an investment bot: a questionnaire on crypto knowledge, suggestions that fit the investor
  profile, the user picks one and the bot invests. The walkthrough uses illustrative data from `lib/demo.ts`.
- Design rules and color roles are in `DESIGN.md`. The bot mascots in `public/stroopies/` come from the Nilo app.
